## Installation

1. **Clone the repository** using GitHub Desktop:
   - Open **GitHub Desktop** and go to `File` → `Clone Repository`.
   - In the "URL" tab, enter the URL of this repository (e.g., `https://github.com/AiVintage/example.repo`).
   - Choose a local directory to save the repository and click **Clone**.

2. **Run the script**:
   - Open the folder where the repository is saved.
   - Open the script file (`script.py`) with your Python editor or IDE.
   - Run the script using Python 3:
     ```bash
     python script.py
     ```
   - Follow the on-screen prompts.
